# Dowe Icons

Dowe Icons is the standalone Zed icon theme extension for Dowe Source Format files.

It provides `Dowe Icons Dark` and `Dowe Icons Light`, with the Dowe logo associated with `.dowe` files.

The extension is published from the `icons` path of the [usedowe/dowe-zed](https://github.com/usedowe/dowe-zed) repository.
